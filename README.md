## About Me

I'm **BTech_IOI**, a maker and developer who works across the whole stack — from bare-metal firmware on ESP32 and Raspberry Pi to fast, content-driven web apps. My GitHub is a mix of original projects and forks I actively hack on, spanning embedded systems, drone flight controllers, mesh networking, desktop ricing (KDE/Hyprland on NixOS), and applied AI.

- 🛰️ **Mesh networking** without infrastructure: self-forming, self-healing **ESP-NOW** networks on ESP32.
- 🚁 **Drone &amp; robotics**: flight controllers and firmware for ESP32, STM32, and Raspberry Pi (Pico/RP2350).
- 🎨 **Fullstack web**: Astro + TypeScript sites, deployed on Netlify; Odoo-based ERP (BTech Grid).
- 🤖 **Applied AI**: self-hosted AI companions, realtime voice, game-playing agents.
- ❄️ **NixOS everything**: dotfiles, WM configs, and system setup on NixOS with the Niri compositor.
- 🐧 **Linux ricing**: KDE Plasma, Hyprland, Quickshell — hand-rolled themes.

# 🌱 Current Projects

🛰️ **[mesh-espnow](https://github.com/btechioi/mesh-espnow)**
ESP-NOW Mesh Network Library v3 — Intelligent, metric-based self-forming/self-healing mesh for ESP32. No Wi-Fi infrastructure, no IP stack, no ESP-MESH.

🚁 **[Drone](https://github.com/btechioi/Drone)**
Drone firmware for Raspberry Pi Pico 2 (RP2350) + GY-87 10DOF — binary RC link over UART0, telemetry over UART1, based on madflight.

📡 **[ExpressLRS-DualBand](https://github.com/btechioi/ExpressLRS-DualBand)**
ExpressLRS fork with ESP32-C3 dual-band (900 MHz + 2.4 GHz) BOTHBANDS firmware support.

🎨 **[My-Blog](https://github.com/btechioi/My-Blog)**
Lightning-fast Astro blog deployed on Netlify with TypeScript.

🤖 **[NOVA](https://github.com/btechioi/NOVA)**
Self-hosted AI companion with realtime voice chat — forked from the AIRI project.

❄️ **[BTechOS-Shell](https://github.com/btechioi/BTechOS-Shell)**
Monochrome, dot-matrix desktop for NixOS.

🖥️ **[kde-fusion](https://github.com/btechioi/kde-fusion)**
KDE Plasma fusion experiments (Rust + QML).

🏢 **BTech Grid** *(private)*
Odoo 20-based retail/inventory/POS ERP platform.
